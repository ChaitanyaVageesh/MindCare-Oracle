# MindCare Oracle User Manual

Welcome to MindCare Oracle, an intelligent framework predicting the requirement logic for obtaining mental health procedures structurally.

## Navigation & Setup

**Step 1:** Download or clone the directory configurations structurally.
**Step 2:** Ensure your host system runs Docker Daemon optimally natively (usually by starting Docker Desktop).
**Step 3:** Use a Terminal to run the launch command structurally: `docker-compose up --build -d`

## Generating Predictions

1. Open a browser and point locally into `http://localhost:3000`. This will boot the user web graphical interface natively.
2. Select parameters corresponding logically to your target persona metrics from the dropdown components seamlessly.
3. Once populated, hit "Predict Outcome". A Risk Logic inference will natively calculate the matching probabilities directly onto the interface synchronously.

## Dashboards 
Access parallel administrative capabilities natively:
- **MLflow Model Analytics:** `http://localhost:5000`
- **Grafana Live Application Metrics Output:** `http://localhost:3001` (login internally via default user `admin` and password `admin`)
- **FastAPI Core Interaction Sandbox:** `http://localhost:8000/docs`
